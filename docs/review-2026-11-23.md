## Pendências e limites

1. HTTP 429 foi observado no runtime ao consultar filas e chamar a senha. O intervalo do chat passou para 30 segundos; a troca pública exigiu pausar consultas de uma das telas. Ainda faltam teste de capacidade e estratégia sustentada para o limite do serviço.
2. A senha 8 permaneceu em atendimento ao final do teste de mensagens. O bloqueio após conclusão foi validado anteriormente no executor Xano; não foi repetido com essa senha na interface pública.
3. A liberação positiva de uma nova conta pelo formulário administrativo foi confirmada após esta revisão, seguida de novo login com perfil Atendente. Isso não comprova concessões concorrentes.
4. Esta revisão não publica nem altera dados ou endpoints do Xano, credenciais ou Secrets. Não foi feita nova inspeção de infraestrutura, carga, backups ou retenção das mensagens.
5. Notificações externas, WhatsApp/SMS/push e satisfação não são apresentados como funcionalidades completas. Atualização periódica não é WebSocket.
6. Históricos das branches podem divergir com conteúdo equivalente; verificar igualdade das árvores no fechamento. O deploy usa `codex/streamlit-deployment-preparation`, entrada `app.py`.

O [checklist do chat](../openspec/changes/atendimento-chat/tasks.md) mantém a validação de capacidade em aberto. As evidências de outubro continuam na [auditoria histórica](project-audit.md).
